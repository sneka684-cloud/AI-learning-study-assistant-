What is Agentic AI?
Agentic AI is an AI system that can understand a task, make decisions and use suitable tools or information to complete the task.

What is RAG?
RAG stands for Retrieval-Augmented Generation. It retrieves relevant information from a knowledge base to provide a useful answer.

What is an AI Student Support Assistant?
It is an AI-based application designed to help students with common academic and college-related questions.

What is Tool Calling?
Tool Calling allows an AI agent to use a specific function such as a calculator or attendance calculator when required.

What is Memory in AI?
Memory allows an AI agent to retain useful information from previous interactions and use it in later questions.

What is Python?
Python is a high-level programming language commonly used for software development, automation, data science and artificial intelligence.

What is Streamlit?
Streamlit is a Python framework used to create interactive web applications.

What is GitHub?
GitHub is a platform used to store, manage and share source code using Git version control.
